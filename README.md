# Primer Latido - App para Mamás Primerizas 👶❤️

Aplicación móvil (iOS & Android) para acompañar a las mamás durante su embarazo con información semana a semana, recordatorios personalizables y acceso a 20 PDFs completos.

## 🎯 Características Principales

✅ **40 semanas de información detallada**
- Tamaño del bebé cada semana
- Desarrollo fetal
- Cambios en el cuerpo materno
- Síntomas normales y de alerta

✅ **20 PDFs incluidos**
- Acceso completo desde la app
- Visor integrado
- Descargables para imprimir
- Disponibles en español e inglés

✅ **Recordatorios personalizables**
- 13 recordatorios configurables
- Toggle ON/OFF por usuario
- Notificaciones programadas
- Categorías: Salud, Nutrición, Ejercicio, Bienestar

✅ **Calculadora de Fecha Probable de Parto**
- Basada en fecha de última menstruación
- Seguimiento semanal automático

✅ **Multiidioma**
- Español e Inglés
- Cambio dinámico en app

✅ **Diseño Pastel**
- Paleta de colores suave y cálida
- Logo "Primer Latido" integrado
- UI/UX amigable para mamás

## 📱 Instalación Rápida

```bash
cd mobile
npm install
npm start
```

Luego escanea el QR con la app Expo Go.

## 📂 Estructura

```
├── mobile/                 # App React Native/Expo
│   ├── src/
│   │   ├── screens/       # 5 pantallas principales
│   │   ├── context/       # Estado global
```

## 📱 Pantallas

1. **Home** - Semana actual, bebé, síntomas
2. **Mi Semana** - Información detallada (slider 1-40)
3. **Recursos** - 20 PDFs buscables
4. **Recordatorios** - Toggle de notificaciones
5. **Perfil** - Idioma, ajustes, info
